VIVRE BIO 🌿

Site e-commerce de VIVRE BIO — transformation de plantes aromatiques en huiles essentielles et extraits naturels.

« Le meilleur de la nature pour vous »

Projet développé par HIMAO Group pour le compte de VIVRE BIO.

🛠️ Stack technique
Next.js (App Router)
Tailwind CSS + daisyUI — thème personnalisé vivrebio aux couleurs de la marque
Font Awesome pour les icônes
Paiement exclusivement à la livraison (espèces ou Mobile Money remis au livreur) — pas d'intégration de paiement en ligne

✨ Fonctionnalités
- Catalogue produits avec filtres par catégorie
- Fiches produits détaillées
- Panier géré côté client
- Tunnel de commande sans compte obligatoire (parcours invité)
- Choix de la zone de livraison avec frais calculés automatiquement
- Pages À propos et Contact
- SEO optimisé (meta tags, données structurées Schema.org, sitemap, images optimisées)

🚀 Démarrer le projet en local
```bash
# Cloner le repo
git clone https://github.com/HIMAO-Group/vivre-bio.git
cd vivre-bio

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

Le site est ensuite accessible sur http://localhost:3000.

📁 Structure du projet
- `app/` — Pages et routes (App Router)
- `components/` — Composants réutilisables
- `public/` — Images, logo, favicon
- `app/globals.css` — Configuration Tailwind + thème daisyUI
